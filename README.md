# 🦟 Dengue México | Epidemiología y clima

## Integración de variables climáticas y epidemiológicas para el desarrollo de un modelo predictivo de dengue en México

Este repositorio contiene un **recurso interactivo para la exploración de datos epidemiológicos y climáticos de dengue en México durante 2025**.

El recurso acompaña el cartel científico **“Integración de variables climáticas y epidemiológicas para el desarrollo de un modelo predictivo de dengue en México”** y permite explorar de forma interactiva parte de los datos integrados durante el desarrollo del proyecto.

---

## 📊 ¿Qué permite explorar?

El dashboard integra información por **entidad federativa y semana epidemiológica**, permitiendo visualizar:

- 🦟 Casos confirmados de dengue
- 🌡️ Temperatura
- 🌧️ Precipitación
- 🗺️ Distribución espacial por entidad federativa
- 📈 Variación temporal durante 2025

La visualización permite explorar conjuntamente la dinámica epidemiológica del dengue y las condiciones climáticas en México.

> **Nota:** Este recurso tiene fines descriptivos y exploratorios. Las coincidencias espaciales o temporales observadas no implican relaciones causales entre las variables climáticas y los casos de dengue.

---

## 🧠 Perspectiva

La integración de información epidemiológica y climática constituye una etapa inicial para la construcción de una **base de datos multivariable**.

Como siguiente etapa del proyecto se plantea evaluar modelos de inteligencia artificial, incluyendo redes **Long Short-Term Memory (LSTM)**, para identificar patrones temporales y explorar la capacidad de las variables epidemiológicas y climáticas para anticipar cambios en la dinámica del dengue.
